New Knowledge Base

Creates a spec-conformant OKF bundle: /KnowledgeBase/<name>/ with index.md, concepts/, raw/.

Import Bundle

Imports an existing OKF directory — its documents, chapters, concept index, and document TOCs must be present and queryable.

Export Bundle

The export is spec-conformant OKF — it includes the concept index and every document TOC, and re-importing reproduces a queryable bundle.

Ingest document

Decomposes the source into chapters (each with concept terms + a one-line summary), writes the document TOC, and updates the concept index. Runs via the bundled least-privilege okf-ingest agent.

Delete knowledge base?

This removes only this bundle's directory (). Documents, chapters, the concept index, TOCs, and raw sources are all removed.
This action cannot be undone.
